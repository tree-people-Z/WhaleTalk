# 鲸语 · B站智能运营助手

鲸语是一个桌面端 AI 角色运营助手，可搜索和分析 B 站视频、生成评论、监听并回复评论。它支持手动巡视和可选自动巡视；自动运行默认关闭。

## 功能

- 以综合排序搜索关键词，并查看播放、评论等热度数据。
- 使用 B 站字幕；没有字幕时，可选本地或云端语音转写补齐文本。
- 每条视频最多抽取三张关键帧，和文字证据一起交给支持视觉的 AI 模型分析。
- 按评分和账号设置决定是否评论；可在评论监听中回复互动。
- 自动视频巡视可以设置 DeepSeek 闲时段，回复检查不受该时段限制。
- 启动后自动检查 GitHub Releases，设置页支持一键下载更新（便携版自动替换并重启）。
- 「评论」标签页可查看自己在评论区的对话（我方评论与网友回复）；「私信」标签页可查看私信会话。
- 评论自动回复会跳过自己发出的评论，避免自问自答。
- 历史记录包含视频链接；运行设置和个人数据保存在本地 `data/` 目录。

## 安装和启动

Windows 用户可从 GitHub Releases 下载便携版 ZIP，解压后双击 `WhaleTalk.exe` 即可启动，无需另行安装 Python 或 VC++ 运行库。请保留同目录的 `_internal/` 运行文件夹。首次启动会在 EXE 同目录创建 `data/`，用于保存设置、登录凭证、数据库、日志和默认人设 `data/persona.md`；已存在的 `persona.md` 不会被升级覆盖。首次使用仍需在应用中配置 AI 服务并扫码登录 B 站。

便携版要求 64 位 Windows 10（1903 或更高版本）或 Windows 11：Qt 6 依赖系统自带的 ICU 组件，便携包不再附带 ICU 动态库，以免与系统组件冲突。

### 检查更新

程序启动后会在后台检查 GitHub Releases，设置页“关于与更新”中也可以手动检查。发现新版本时会在状态栏提示，并把设置页的按钮变成“更新到 vX.Y.Z”；程序运行期间每 6 小时复查一次。便携版点击“立即更新”后会下载新版本、自动替换程序文件并在退出后重启，`data/` 目录保持不变；源码运行请直接 `git pull`。

### 评论对话面板

「评论」标签页按时间列出本程序发出过的评论。选中一条后，右侧会加载该评论楼层下的完整对话：我方评论、网友回复，以及机器人自己发出的回复（标记为“我”）。加载网友回复需要已登录 B 站账号。

应用运行期间会按设置间隔自动检查回复（需要开启评论监听）。检测到新回复时：

- 状态栏会提示最新一条回复，并写入控制台日志；
- 「评论」标签会显示未读数量（例如“评论 (2)”），新回复对应的楼层会带 🔔 标记；
- 打开「评论」页会看到顶部提醒条和最新对话，未读数清零。

是否自动回复由设置里的“启用自动回复”开关决定；关闭时仍会提醒和展示回复。

### 私信面板

「私信」标签页展示 B 站私信会话列表和每个会话的消息记录，便于查看账号收到的私信。该页面目前只读，不会自动回复私信；自动回复只针对评论区中回复你评论的用户。

从源码运行需要 Python 3.10+。Windows 双击 `start.bat`；其他系统运行 `./start.sh`。首次启动会检查并安装 `requirements.txt` 中缺少的程序依赖。也可以手动运行：

```bash
python main.py
```

首次启动后，在设置页配置 AI 服务与 API 密钥，并扫码登录 B 站。配置密钥后，先使用“现在巡视一轮”验证，再自行决定是否打开自动运营。

### 语音识别（可选）

设置页「语音转写」提供三种模式：

- **关闭**：不使用语音转写。
- **本地识别（medium）**：点击“下载本地识别组件和模型”后，先下载约 92 MB 的本地识别组件（保存到 `data/transcription`，升级程序时保留），再下载 `medium` 语音模型到 `data/models/faster-whisper`（约 1.5 GB）。音频只在本机用 CPU int8 转写，不会上传。为保证中文识别效果，本地模式只提供 `medium` 模型。
- **云端识别（OpenAI 兼容接口）**：填写接口地址（默认 `https://api.openai.com/v1`）、API Key 和模型（默认 `whisper-1`）。程序会用 ffmpeg 把音频压成 MP3（最长 15 分钟）并上传到该服务的 `/audio/transcriptions` 接口；音频会发送到所配置的服务商，不再下载本地模型。

无法访问 `huggingface.co` 时，本地模型会自动改用 `hf-mirror.com` 镜像下载。源码版由 pip 安装 `faster-whisper`，但同样只在本地模式使用。

### 手动放置模型（下载太慢时）

如果自动下载 `medium` 模型很慢，可以自己下载 faster-whisper 的 CTranslate2 格式模型，放到 EXE 同目录下的：

```
WhaleTalk\data\models\faster-whisper\medium\
```

例如完整路径：

```
C:\Users\<你的用户名>\Desktop\WhaleTalk-Windows-x64\WhaleTalk\data\models\faster-whisper\medium\
```

**只需要且只需要这 4 个文件**（`.gitattributes`、`README.md` 不需要）：

| 文件 | 大小（字节） |
|---|---|
| `config.json` | 2,257 |
| `model.bin` | 1,527,906,378 |
| `tokenizer.json` | 2,203,239 |
| `vocabulary.txt` | 459,861 |

下载地址（HuggingFace 原站或镜像均可）：

- https://huggingface.co/Systran/faster-whisper-medium/tree/main
- https://hf-mirror.com/Systran/faster-whisper-medium/tree/main

放置后：

1. 确认 `data\transcription` 里的识别组件已经存在（如果没有，先在设置页点一次“下载本地识别组件和模型”，92 MB）；
2. 重启程序；程序检测到完整的 `medium` 目录后会直接加载它，不再联网下载模型。也可以在设置页点“打开模型目录”直接打开目标文件夹；
3. 日志里会出现「使用手动放置的本地语音识别模型: data\models\faster-whisper\medium」。

在线下载方式仍然保留；`data/` 目录在程序升级时会保留。也可以从其他机器 HuggingFace 缓存中的 `models--Systran--faster-whisper-medium\snapshots\<hash>\` 里复制这 4 个文件。

音频提取和画面抽帧需要 FFmpeg。程序会按顺序查找：系统 PATH → 程序目录 `ffmpeg.exe` / `ffmpeg\bin\ffmpeg.exe` → `data\ffmpeg\ffmpeg.exe` → `C:\ffmpeg\bin\ffmpeg.exe`；也可以直接把 ffmpeg.exe 放到程序目录。每条视频最多抽取三张压缩画面。配置的 AI 服务需要支持视觉输入；DeepSeek `deepseek-flash` 支持图像输入。音频、抽帧等临时文件会在处理后删除。

## 默认行为

- 自动运营关闭；用户手动开启后才按设置运行。
- 每关键词最多搜索 5 条，搜索结果按关键词轮询交错、每轮随机关键词顺序；每条视频分析参考前 15 条热门评论。
- 想做“每轮分析 1–2 条视频”：把「巡视间隔」设为 5–10 分钟、「每轮分析视频数」设为 1–2；符合条件的视频才评论，不强制每轮必须发评论。
- 自动巡视间隔 5–30 分钟；评论回复检查每分钟一次。
- DeepSeek 视频巡视默认仅在配置的闲时段运行；回复检查全天运行。
- 每日评论上限 96（实测 B 站平台上限）、评论分数门槛 10；同一视频冷却 7 天。
- 公开评论 @账号主人默认关闭；开启后评论评分达到“评论 @我 的最低评分”（默认 13）时会在评论中 @主人，可在设置页调整门槛。
- 视频标题或字幕明确要求“把这个视频 @ 给主人/转告主人”时，会按指令评论并 @主人，不再受评分门槛限制（仍需开启“在评论中 @我”开关）。
- 评论区遇到其他“鲸鱼娘”账号时会主动打招呼：每条视频最多 2 个、每轮最多 5 个，可在设置里关闭或调整每视频上限。
- 开启“回复别人的有趣评论”时，会回复评论区里直接问/回应鲸鱼娘的顶层评论（例如“鱼会回复吗”）：每视频最多 1 条、每轮最多 3 条；“回复其他人”“仅处理主人”开关同样生效。
- 评论面板跟踪所有已发出的评论和回复（顶层评论、回复网友、打招呼、互动回复），点击可查看对应对话。\n- 历史记录中的“值得”表示达到评论门槛（或视频含明确 @主人 指令），不再是 AI 的独立评分字段。
- 仅画面、没有字幕或转写文本的判断会降低置信度，并阻止自动公开评论。

所有设置均可在界面中更改。B 站平台对自动操作有自己的规范和限制，请谨慎设置评论频率并遵守平台规则。

### 遇到 B 站 412 风控

程序会自动做这些保护：

- 评论请求串行执行，并在 2–3 秒基础上加随机间隔，避免规律性的机器请求；
- 分析用的评论页缓存 2 分钟，短时间重复分析同一视频不会重复请求；
- 一旦遇到 412，自动暂停评论请求、分析周期和回复检查 30 分钟，冷却后自动恢复；
- 日志只输出简短错误，不再刷整页 HTML。

如果仍然频繁 412，可以按下面顺序排查：

1. 只运行一个程序实例（多个实例会同时请求同一账号/IP）；
2. 把「评论回复检查间隔」调到 10–15 分钟、「评论监听间隔」调到 20–30 分钟；
3. 减少「每轮最多分析视频数」（例如 10 条以内），不要反复点“立即巡视”；
4. 先停半小时到一小时，期间不要重启程序、不要让自动运营继续请求；
5. 在设置页重新扫码登录，让 cookies/buvid 更新；避免共享代理、VPN 或机房 IP；
6. 检查系统时间是否准确（偏差过大会导致签名校验失败）。

长时间仍 412 通常说明账号或出口 IP 被重点风控，只能更换网络或等待更久。

### 遇到评论发送上限（12014）

B 站返回 `12014 已达到当前评论发送上限` 时，程序会暂停发评论到次日 00:05，并在冷却期间跳过分析与回复检查。实测账号的 B 站评论上限约为 96 条/天；把「每日最大评论数」设为 96，并适当拉长巡视间隔，不要连续多轮评论。
## 开发和验证

```bash
python -m pip install -r requirements.txt
python -m pytest -q
python -m compileall -q core gui utils tests
```

可选本地转写依赖单独列在 `requirements-transcription.txt`，不会随基础依赖自动安装。

### 构建 Windows 便携版

```bash
python -m pip install pyinstaller
python -m PyInstaller --clean --noconfirm WhaleTalk.spec
```

产物在 `dist/WhaleTalk/`，将整个文件夹压缩为 ZIP 后即可发布到 GitHub Releases。构建机不需要在 PATH 中保留其他 SDK 的 `bin` 目录：`WhaleTalk.spec` 会丢弃 Python 安装目录之外收集到的 DLL，避免本机其他软件（如 poppler、libheif）的同名动态库混入并覆盖系统组件。

发布便携包时把 `ffmpeg.exe` 和 `FFMPEG_LICENSE.txt` 复制到 `dist/WhaleTalk/`，程序会优先使用这个本地 ffmpeg；这样用户机器没有安装 ffmpeg 也能直接抽帧和转写。官方便携包已内置 `ffmpeg.exe`。

## 本地数据与隐私

API 密钥、B 站登录凭证、配置、历史数据库、日记和识别模型保存在 `data/` 下并由 Git 忽略。请勿提交本地配置或凭证。画面缩略帧仅为分析请求临时生成；发往视觉模型的图片与分析文本会按所配置 AI 服务的隐私政策处理。
